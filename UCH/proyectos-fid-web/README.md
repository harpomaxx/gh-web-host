# Página web — Proyectos FID UCH 2026

Sitio estático con resumen navegable de los 8 proyectos FID vigentes 2026.

## Cómo ver

Abrir en un navegador:

```bash
xdg-open index.html
```

O servir localmente:

```bash
python3 -m http.server 8000
```

y entrar a `http://localhost:8000`.

## Archivos

- `index.html` — contenido y estructura de navegación por proyecto.
- `profesores.html` — mapa de participación por profesor/integrante, con enlaces desde los nombres del listado principal.
- `styles.css` — estilo sobrio/académico con paleta neutra.

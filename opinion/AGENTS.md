# AGENTS.md

Guidance for coding agents working in this directory.

## Project overview

This is a small static opinion/essay site. Source posts live in `posts/*.md`; `build.py` converts them into root-level `postNNN.html` files and regenerates `index.html` using templates from `templates/`.

Generated HTML is intentionally committed because the site is served as static files.

## Important files

- `build.py` — Python 3 static-site generator; no external dependencies.
- `posts/` — Markdown source posts. Edit these for content changes.
- `templates/post.html` — individual post HTML template.
- `templates/index.html` — homepage/index template.
- `style.css` — site theme.
- `index.html`, `postNNN.html` — generated output; do not edit directly.

## Workflow

After changing any of the following, run the build:

```sh
python3 build.py
```

Run this after edits to:

- `posts/*.md`
- `build.py`
- `templates/*.html`
- `style.css` if visual output should be checked with current generated pages

Basic validation:

```sh
python3 -m py_compile build.py
python3 build.py
```

## Writing posts

Create posts as `posts/postNNN.md` with front matter:

```markdown
---
title: Post title
date: YYYY-MM-DD
subtitle: Optional subtitle
summary: Optional index/meta summary
author: Optional author metadata
image: Optional sharing image URL/path
draft: true # optional; excludes from build
---

Body text...
```

Supported Markdown is intentionally limited: headings, paragraphs, links, images, emphasis, inline code, fenced code blocks, blockquotes, lists, horizontal rules, and raw HTML. Tables should be written as raw HTML.

## Editing rules

- Prefer editing Markdown sources and templates, not generated HTML.
- If generated HTML is out of date, regenerate it with `python3 build.py`.
- Keep `build.py` dependency-free unless the user explicitly asks otherwise.
- Preserve the minimal black-and-white editorial style.
- Generated files include `<!-- Generated by build.py; do not edit by hand. -->`.

## Notes

`build.py` removes stale generated post pages when their source Markdown file is missing or marked as draft. The source filename determines the output slug: `posts/post003.md` becomes `post003.html`.

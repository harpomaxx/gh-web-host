Preservation and web methodology

This web archive is generated from llm-normalized/. That directory is an interpretive UTF-8 derivative containing deterministic repairs plus accepted high-confidence GLM repairs. It does not replace raw/, which remains the authoritative preservation source.

Importer

  • Python standard-library email parsing reads all numbered extensionless source files deterministically.
  • MIME headers are decoded; missing or malformed dates, subjects, senders, and message IDs are recorded as warnings.
  • text/plain body parts are preferred. HTML-only email is converted to plain readable text with scripts, frames, objects, and remote image behavior discarded.
  • The generated message body is escaped/safe HTML. Raw email HTML is never injected into archive pages.
  • Each message receives source path, byte size, SHA-256 checksum, unresolved-character count, and a text/plain source copy under /source/NNNN.txt.

Threading

Thread reconstruction uses References first, then In-Reply-To. Messages without usable reply headers are grouped only by conservative normalized subject within the same year-month window, avoiding broad merges of unrelated conversations.

Safety and accessibility

  • No remote images are loaded from preserved messages.
  • A static Content Security Policy blocks objects and restricts scripts to same-origin files.
  • Pages use semantic HTML, visible focus states, wrapping for long headers and URLs, and responsive layouts down to 320px.
  • JavaScript adds search, keyboard shortcuts, and theme switching; ordinary browsing and message reading remain available without JavaScript.

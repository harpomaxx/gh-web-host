On Fri, Aug 02, 2002 at 03:52:10PM -0300, Sebas wrote:

Che, tengo que dar clases a distancia de física y química, por lo
tanto, deberé emlear ecuaciones... ¿hay alguna herramienta útil para
ello? Quiero decir, hacer las ecuaciones como sigue:
 
p*v = p1*v1
---- -----
t t1
 
es entendible, pero es incómodo y visualmente antiestético...
adjuntar un archivo de word me parece una mierda... hay alguna
otra opción?
Nada muy complejo, recuerden que soy estudiante de medicina y estaré
explicando química y física básicas a aspirantes a ingresar a mi
facultad.

Estas limitado a lo que sea que tu alumno pueda leer.
Podes usar TEX (pronunciado "tekh" ya la ultima letra es una chi
mayuscula, no una equis) que es el paquete de software que se usa
para escribir libros de verdad en las editoriales de verdad.
TEX incluye un paquete LATEX para ecuaciones y otras mierdas.
Pero tu alumno no creo que tenga ningun programa para formatear TEX.

Entonces podrias convertir a algun formato estandar tales como
ps, html, o pdf.

HTML tiene la posibilidad de representar las ecuaciones como tales,
pero son adiciones recientes, asi que lo mas probable es que el conversor
que uses genere las ecuaciones como imagenes.

ps es un lenguaje de impresoras, y pdf es lo mismo pero comprimido y por
lo tanto muy util para distribuir cosas.

Te recomiendo por lo tanto que le entregues el material como pdf.

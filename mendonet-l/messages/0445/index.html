On Mon, Mar 03, 2003 at 12:02:18AM -0300, Sebas wrote:

Che, mi vieja usa outlook express, y cada vez que le llega una de esas
propagandas de "ciudad", se conetca automáticamente... si interrumpís
la conexión lo intenta de nuevo y así ad eternum... ¿cómo lo impido?

Tenes que mirar el codigo fuente del mensaje para ver como es que se
esta conectando automaticamente.
Veo 2 posibilidades:
1. El mail esta en formato HTML e incluye imagenes que no estan adjuntas
al mail y por lo tanto las tiene que bajar de un servidor web para poder
mostrar el mensaje
2. Hay un fragmento de programa javascript en el cuerpo HTML del mensaje
que esta ejecutando un comando para conectarse de prepo, hagas lo que hagas.

La solucion consta de varios pasos:
1. Desactivar el discado automatico en la configuracion de Internet Explorer.
La conexion automatica es para imbeciles. Y tu vieja seguramente no lo es.
2. Configurar Outlook Express para que "comparta" la configuracion de
conexion con Internet Explorer.
3. Desinstala OE y reemplazalo con Mozilla
(http://www.mozilla.org) que es mas seguro, mas funcional y cumple con los
estandares establecidos.

El paso 3 es opcional si el problema es el 1, obligatoria en el otro caso.

Estuve revisando y no encontré nada que pareciera evitarlo... ¿podrían
ayudarme?

No uses OE y no vas a tener estos problemas tan estupidos.

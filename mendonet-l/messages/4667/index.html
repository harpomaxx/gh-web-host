Alerta de Virus: W32/Nimda.A hace temblar la red.
Este nuevo virus de alta capacidad de reproduccion se contagia con solo leer un mail sin necesidad de abrir el attach, ademas tambien se expande por las redes locales y desde servidores web.

Como remover W32/Nimda.A@mm

La infeccion de este virus no se puede remover manualmente de los archivos, ya que los infecta con codigo binario, pero si puedes reconocer si estas infectado y eliminar el virus del sistema. Para ellos debes seguir los siguientes pasos :

1) Haz click en Inicio, luego en Ejecutar.

2)Luego escribe lo siguiente y despues haz click en Aceptar:

edit c:\windows\system.ini

Se abrira el editor de MS-DOS

NOTA: Si Windows esta instalado en otro directorio, haz la sustitucion correspondiente.

3)Localiza la linea que comienza con "shell="

4)Posiciona el cursor inmediatamente despues del signo igual.

5)Presiona Mayusculas+Fin(o Shift+End), para marcar hasta el final de la linea y Supr (o Del) para borrar lo marcado.

6)Ahora escribe en lugar de lo que borraste lo siguiente:

explorer.exe

La linea ahora se debe ver asi:

shell=explorer.exe

7)Cierra la ventana, guarda los cambios cuando te pregunte y reinicia tu PC.

Una vez que hayas realizado estos cambios tu sistema estara libre del virus pero no asi tus archivos infectados. Lo mas recomendable es que actualizes tu antivirus y lo utilizes para limpiar tu sistema. Tambien puedes utilizar la herramienta gratuita que ofrece la empresa Trend Micro para eliminar este virus y que puedes bajar haciendo click AQUI.

NOTA: Estas herramientas probablemente eliminen los archivos infectados de tu computadora y los archivos Admin.dll y Riched20.dll, estos dos ultimos los puedes reincorporar a tu sistema desde los .cab de los CD-Rom del Microsoft Windows o Microsoft Office.

Usuarios de Outlook: El virus usa una falla de "Microsoft IE MIME Header Attachment Execution" para dejar e-mails. Para arreglarlo, pueden descargue el patch del sitio de Microsoft.

http://www.microsoft.com/technet/security/bulletin/MS01-020.asp

Usuarios de IIS: El virus utiliza para su propagacion desde IIS un bug del "Microsoft Web Server Folder Traversal". Pueden descargar el patch del sitio Microsoft.

http://www.microsoft.com/technet/security/bulletin/ms00-078.asp

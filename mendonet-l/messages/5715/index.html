Libertad 0: libertad para usar y realizar las tareas para las cuales se

el software.
Libertad 2: libertad para estudiar y aprender sobre como esta hecho y
funciona el software, pudiendo realizar un trabajo derivado del mismo.
Libertad 3: libertad para modificar el software y adaptarlo a tus
necesidades (por vos mismo o pagandole a alguien que sepa programar
para que lo haga).

Es que es asi!!!!!
El DOS tenia una restriccion en los nombres de archivo que podia generar: el
nombre podia consistir en no mas de 8 letras o numeros, seguidos de un
punto,
seguidos de no mas de 3 letras o numeros.
Aparte de letras y numeros, se podian usar algunos signos de puntuacion y
tambien
el espacio en blanco (aunque casi nadie sabia como hacer esto)

Conclusion: cuando hicieron Windows 95, decidieron que los nombres de
archivos
iban a poder consistir en hasta 255 caracteres, letras numeros, signos de
puntuacion y
espacios.
Obviamente, la estructura interna de los discos se modifico para acomodar
estos nombres
tan largos. Si vos metias un disquette modificado internamente para acomodar
nombres
largos (lo que se llama sistema de archivos VFAT) cuando lo metias en una
maquina que
tenia DOS, leeria basura, entonces el Windows graba el nombre largo de una
forma invisible
para el DOS y ademas graba un nombre corto abreviando el nombre largo
correspondiente.
El nombre corto es compatible con DOS, o sea del tipo xxxxxxxx.xxx
Toda esta duplicidad de nombres el Windows la realiza cuando en nombre largo
original no
es del todo compatible con DOS.
En el caso del archivo CPP0720x.034 aparentemente el nombre es compatible
con DOS.
Posiblemente, el archivo contenga un espacio en el nombre al principio o al
final, o tal vez en
el medio. Deberias ver cuidadosamente eso (se que es dificil por cuanto los
espacios en
blanco son invisibles).
De ultima, usando DOS en la maquina que tiene DOS, renombra el archivo a
mano antes de
procesarlo. Por ejemplo el comando:

    REN CPP07~1.034 CPP0720x.034

haria el truco.

On Tue, Nov 20, 2001 at 04:15:15PM -0300, Lupus wrote:
> Cheses... estoy muy preguntoso últimamente...
> 
> Cuál es la mecha con java??

Que es un lenguaje de programacion moderno (orientado a objetos, y todas esas
pelotudeces) totalmente portable, porque los programa en Java son compilados
a un lenguaje de maquina virtual (o sea que no existe) que a su vez es
interpretado por otro programa llamado Maquina Virtual de Java.

Si lo comparas con el C++ (en cuya sintaxis se parece mucho), le han sacado las
caracteristicas mas concretas y cercanas a a la real arquitectura de una
computadora electronica (por ejemplo los punteros) y ha quedado una especie de
C++ light para señoritas, o C++--.

Otros lenguajes prometen portabilidad (poder usar el mismo programa en cualquier
maquina) pero para escribir un programa en uno de los lenguajes tradicionales
mas portables (el C), por lo general tenes que llenar el programa de condiciones
(si esta maquina es Windows usar esto, si es Linux usar esto otro, si es una
Commodore 64 usar esta otra cosa).
En el Java hay una sola maquina (la maquina virtual de Java) y si la implementacion
concreta de la misma cumple con los estandares entonces funciona siempre igual.

Es como tener un emulador de Commodore 64: ya no existen las C64, pero tenes emuladores
de la misma para Windows, Linux, DOS, Mac.... La maquina virtual de Java es un
emulador de Maquina virtual de Java, una maquina teorica que nunca existio en la
realidad (aunque la empresa Tranmeta donde trabaja Linus Torvalds estaba inventando
una).

El registro es una base de datos jerarquica que almacena pares 
(clave,valor). La "clave" es un identificador unico de cada valor. Una 
clave puede contener ademas de valores, subclaves, asi como un 
directorio puede contener archivos y directorios.
El registro esta almacenado en 2 archivos en la version de Windows que 
vos usas. Si borras alguno de esos archivos, haces desaparecer muchos 
datos no solo los que te interesaba que desaparecieran.

Perfecto. Basta con que pongas wget -c -r -k URL para que baje 
recursivamente todos los archivos accesibles desde el URL indicado. La 
-c indica que si se interrumpe la descarga de un archivo luego la 
continue desde donde se corto. La -k indica reescribir el codigo HTML 
para permitir la navegacion local de los archivos bajados.
